## Performance regression fixes detected (1)

### 1. eager-work

**Fix location:** `src/vs/workbench/contrib/interactive/browser/interactive.contribution.ts:84` (`LEFT`)  
**Blamed base line:** `src/vs/workbench/contrib/interactive/browser/interactive.contribution.ts:84`  
**Introducing path:** `src/vs/workbench/contrib/interactive/browser/interactive.contribution.ts`  
**Introducing commit:** `eee81511401e20ac3ba252a78b0a99a732273cd6`  
**Mechanism family:** `eager-work`  
**Performance category:** `startup`  
**Confidence:** 0.98

**Mechanism:** A blocking startup contribution forced a delayed notebook service and its provider store to instantiate solely to query/register the Interactive notebook type, eagerly executing synchronous constructor and metadata setup before any notebook use.

**Symptom:** Ordinary workbench restoration paid notebook provider initialization work despite restoring no Interactive Window or notebook.

**Fixed behavior:** The Interactive notebook descriptor is now placed in a lightweight in-memory registry at module evaluation. NotebookProviderInfoStore consumes it only when notebook provider information is first requested, so ordinary startup no longer instantiates NotebookService/NotebookProviderInfoStore or performs their storage and extension-metadata setup on the BlockRestore critical path.

**Evidence:** In the base revision, the BlockRestore contribution constructor injected INotebookService at line 84 and immediately called getContributedNotebookType('interactive'); that method accesses NotebookService.notebookProviderInfoStore, whose lazy getter creates NotebookProviderInfoStore. The store constructor synchronously reads its storage memento, registers extension listeners/handler, and processes notebook/editor metadata. INotebookService is registered Delayed, so the constructor call defeated that laziness during blocking workbench restoration even when no notebook was opened. The diff removes both the injection and query and replaces them with one module-load metadata registration.
