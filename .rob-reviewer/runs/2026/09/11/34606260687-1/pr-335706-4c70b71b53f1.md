- Scaling input: Number of usage reports U in one active turn, generally model-call and refinement events rather than token-stream events. The diff adds one bounded actual-model resolution per report and can forward the one-time transition from unknown to known actual model.
- Effective concurrency: Observable autoruns process state updates synchronously in sequence. The diff adds no parallel lookup, IPC request, limiter, or burst mechanism.

- Mechanism confidence: High confidence from the reducer, usage observable, model lookup implementation, and sink path that no boundary or collection-wide work was added.

- Expensive boundaries:

- Verdict: No reportable regression: the diff supplies richer model metadata to an existing fixed-cost widget update path without increasing DOM size, forcing layout reads, or introducing unbounded render frequency.
