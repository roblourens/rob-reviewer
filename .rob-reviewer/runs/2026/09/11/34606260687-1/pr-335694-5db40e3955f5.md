- Scaling input: Focus transitions, not workspace size or result count. Each transition affects at most the newly focused and previously focused elements.
- Effective concurrency: One active focused element at a time in a document; focus transitions are serialized by the browser event loop.
- Cache behavior: Normal browser stylesheet matching applies; there is no application cache or miss path. The shared CSS rule is loaded once and reused across all Toggle instances.
- Mechanism confidence: High: the changed CSS consists only of a simple class/:not/:focus selector and a border declaration on the focused node.
- Magnitude uncertainty: Exact style/repaint duration is browser-dependent, but selector scope is one focused element and no layout read/write feedback loop exists.
- Expensive boundaries: none found
- Verdict: No reportable regression. The new focus paint is bounded and is the intended visible behavior, with no synchronous layout mechanism or repeated subtree work.
