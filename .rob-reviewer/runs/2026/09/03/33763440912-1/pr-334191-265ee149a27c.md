- Magnitude uncertainty: Exact repaint duration and GPU raster cost vary by theme, device scale, and viewport, but the diff adds only constant border/background paint geometry and no selector expansion, animation, forced layout read, or extra DOM node, so there is no concrete regression mechanism despite those measurement uncertainties.

- Verdict: No reportable performance regression. Replacing one sticky border with one pseudo-element and reshaping existing connector pseudo-elements preserves constant per-rendered-row work; tokenized font sizes and colors do not add hot-path computation.

- Magnitude uncertainty: The aggregate number of themed fixture invocations can vary by CI selection, but each invocation uses small static arrays and the code is excluded from shipped runtime paths.

- Verdict: No reportable performance regression. The extra bounded in-memory fixture setup is test-only and negligible, while it enables the visual state under test.
