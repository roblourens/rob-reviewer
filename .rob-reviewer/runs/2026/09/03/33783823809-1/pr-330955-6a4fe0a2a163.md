## Performance regression fixes detected (1)

### 1. repeated-work

**Fix location:** `src/vs/platform/agentHost/node/agentHostSessionTitleController.ts:519` (`RIGHT`)  
**Blamed base line:** `src/vs/platform/agentHost/node/agentHostSessionTitleController.ts:523`  
**Introducing path:** `src/vs/platform/agentHost/node/agentHostSessionTitleController.ts`  
**Introducing commit:** `4fae990dca5664473c8a4558620a9076702ace48`  
**Mechanism family:** `repeated-work`  
**Performance category:** `latency`  
**Confidence:** 0.92

**Mechanism:** Every active-agent side-chat turn could read title metadata and inject guidance forcing an unnecessary rename\_chat tool invocation.

**Symptom:** Side-chat sends paid avoidable metadata I/O and rename-tool latency before completing the side answer.

**Fixed behavior:** Side-chat turns now exit title preparation before the metadata read and rename\_chat guidance, removing that repeated work from the answer path.

**Evidence:** SessionTitleContribution.onOutgoingTurn awaits prepareInstructionForAgent on every outgoing turn. In the base revision, line 523 awaited \_readPersistedTitleMetadata, which opens the session database and reads metadata; for an automatic title the method then returned an instruction that explicitly requires rename\_chat. The new SideChat-origin guard returns before both operations, and the added test verifies this path returns undefined for a side chat.
