### 1. boundary-fanout

**Fix location:** `src/vs/sessions/contrib/github/browser/github.contribution.ts:296` (`RIGHT`)  
**Blamed base line:** `src/vs/sessions/contrib/github/browser/github.contribution.ts:288`  
**Introducing path:** `src/vs/sessions/contrib/github/browser/github.contribution.ts`  
**Introducing commit:** `2ae61ac0521a646704be58617b3ea56a2ed9cd09`  
**Mechanism family:** `boundary-fanout`  
**Performance category:** `network`  
**Confidence:** 0.98

**Mechanism:** Unconditional per-session CI polling kept every inactive open draft PR on a 60-second network refresh loop, so background request volume scaled with the number of distinct inactive draft PRs tracked by the sessions contribution.

**Symptom:** Continuous GitHub check-runs API traffic and associated response processing for inactive draft sessions whose CI status was not being displayed.

**Fixed behavior:** For an open draft PR, the contribution still performs one initial status refresh, but it registers the 60-second CI poller only while that draft's session is active. Inactive draft models therefore stop generating recurring GitHub check-runs requests, while non-drafts retain the previous polling behavior. Shared model references and refresh-promise coalescing preserve deduplication for duplicate keys and simultaneous refreshes.

**Evidence:** Base line 288 unconditionally registered GitHubPullRequestCIModel.startPolling() for every open PR after the status autorun acquired its CI model. GitHubPullRequestCIModel schedules one refresh every 60 seconds, and each refresh reaches GitHubPRCIFetcher.getCheckRuns(), which issues a GET to /repos/{owner}/{repo}/commits/{sha}/check-runs. The contribution iterates every tracked session and PR identity, so inactive draft sessions generated one recurring request per distinct draft PR. The changed draft branch now observes active-session state and only owns startPolling() while that session is active; the added test proves inactive drafts receive the one initial refresh but zero polling registrations.
