- Mechanism confidence: High: timer ownership, listener disposal, List.splice, and submenu layout callbacks are directly traced.

- Expensive boundaries: none found
- Verdict: No reportable regression. There is no accumulating timer/listener retention, and in-place updates do not add a hotter or more scalable layout path than the previous reconstruction.
