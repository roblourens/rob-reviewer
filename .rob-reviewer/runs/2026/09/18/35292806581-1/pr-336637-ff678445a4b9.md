## Performance regression fixes detected (1)

### 1. eager-work

**Fix location:** `src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts:2378` (`RIGHT`)  
**Blamed base line:** `src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts:2378`  
**Introducing path:** `src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts`  
**Introducing commit:** `c6b3beee5ebbe376d6cccc4b22aaf4c146232d23`  
**Mechanism family:** `eager-work`  
**Performance category:** `network`  
**Confidence:** 0.94

**Mechanism:** All server-tool descriptions and schemas were forced eager on each Copilot session launch/resume, so rarely used artifact List/Remove metadata consumed prompt serialization and model-context tokens even when never invoked.

**Symptom:** Unnecessary initial prompt bytes/tokens on artifact-enabled Copilot sessions, increasing request payload and model-context overhead.

**Fixed behavior:** Artifact List and Remove metadata is excluded from the eager Copilot tool set when tool search is available and loaded through the existing search mechanism only when needed; Add remains eager and unsupported models retain the previous fallback.

**Evidence:** Before this PR, CopilotAgentSession.\_createServerSdkTools mapped every enabled server tool to `defer: 'never'`; CopilotSessionLauncher calls createServerSdkTools on each launch/resume and includes those definitions in the SDK tool array. Artifact list/remove definitions are only needed when those uncommon operations are requested, yet were therefore loaded into every artifact-enabled Copilot model context. The changed line now maps definitions marked deferLoading to `defer: 'auto'` when the already-established tool-search gate is active, while artifactServerTools marks only List/Remove deferred and leaves Add eager. Tests trace discovery through the existing tool-search client round-trip in both new and restored chats.

- Verdict: No reportable regression. Persistence remains coalesced to one write per mutating batch, same-session ordering is preserved, and the added promotion work is bounded to an uncommon transition.
