## Performance regression fixes detected (1)

### 1. repeated-work

**Fix location:** `src/vs/workbench/contrib/chat/browser/widget/input/chatInputPickerResponsiveLayout.ts:145` (`RIGHT`)  
**Blamed base line:** `src/vs/workbench/contrib/chat/browser/widget/input/chatInputPickerResponsiveLayout.ts:142`  
**Introducing path:** `src/vs/workbench/contrib/chat/browser/widget/input/chatInputPickerResponsiveLayout.ts`  
**Introducing commit:** `d77fa1711fcb0501c1049795fd8fbaddfb3a57ea`  
**Mechanism family:** `repeated-work`  
**Performance category:** `layout`  
**Confidence:** 0.97

**Mechanism:** The responsive chat picker layout sorted items by repeatedly reading live DOM geometry in the comparator and then reread every item's geometry for fit checks, multiplying synchronous layout-sensitive reads on startup, resize, and picker-content mutations.

**Symptom:** Excessive synchronous DOM measurement increased responsive picker layout latency; profiling/benchmark evidence in the reviewed change shows lower layout counts and per-call time after snapshotting bounds.

**Fixed behavior:** The new \_getVisibleItemBounds snapshots each connected visible picker's bounds once per check and sorts those snapshots, removing O(n log n) repeated synchronous geometry reads from comparator execution while preserving visual ordering.

**Evidence:** On chat input construction and every ResizeObserver/MutationObserver-triggered layout, layout() orders visible picker items and repeatedly calls \_fitsAvailableWidth while compacting. In the base revision, \_getOrderedVisibleItems filtered with getClientRects(), then its sort comparator called getBoundingClientRect() for both operands on every comparison; \_fitsAvailableWidth subsequently measured every item again. The changed helper records one DOMRect per visible item and all ordering/fit checks reuse that snapshot. The added tests cover right-to-left/reverse ordering and hidden items, while the PR's measured scenario reports reduced Chromium layout count on three-picker narrow/resizing paths.
