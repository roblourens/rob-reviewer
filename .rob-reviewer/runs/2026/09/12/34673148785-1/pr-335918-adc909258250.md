- Critical path: Command resolution is local for the reserved alias; mode application and one SDK commands.invoke call must complete, followed by policy formatting and one awaited file write before the link response is emitted.
- Scaling input: Number of explicit /sandbox-policy invocations and size of the SDK policy text; expected policy output is small and each invocation creates one snapshot.
- Effective concurrency: No batching or coalescing is used; each accepted user invocation performs its own SDK call and write. Normal session command handling governs concurrent turns.
- Cache behavior: Command resolution bypasses runtime discovery for the reserved alias. Policy output is intentionally not cached so each link preserves its invocation-time snapshot.
- Mechanism confidence: High confidence in the one-call/one-write critical path from the changed code and tests.
- Magnitude uncertainty: Users could invoke the command repeatedly, but snapshots are small, explicitly requested, and removed with session data; no realistic high-impact growth was established.
- Expensive boundaries:

- Verdict: No reportable regression: the added boundary work is necessary, bounded per explicit user action, and retained files have session-scoped cleanup.

- Critical path: Markdown rendering synchronously scans anchors once and identifies preview metadata. - Scaling input: Number of anchors in one Markdown part, number of query-bearing links, streaming rerender batches, and number of persisted policy-link responses restored.
- Effective concurrency: Anchor inspection is synchronous and serial in one DOM scan; file stats are launched asynchronously per preview widget with no explicit limiter, but realistic preview-link cardinality is the number of explicit policy invocations.
- Cache behavior: Already-rendered anchors are detected by class within a render. Full rerenders dispose registrations and recreate DOM/widgets; there is no stat cache in the widget.
- Mechanism confidence: High confidence in the added per-anchor metadata check and one asynchronous stat per preview widget; low evidence of material user-visible cost.

- Verdict: No reportable regression: the implementation avoids a second anchor scan, performs only linear lightweight checks for ordinary links, and preview-link filesystem work is low-cardinality and off the render critical path.
