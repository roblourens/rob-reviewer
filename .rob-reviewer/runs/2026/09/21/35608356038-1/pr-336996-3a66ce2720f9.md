## Performance regression fixes detected (1)

### 1. cleanup-lifecycle

**Fix location:** `extensions/vscode-test-resolver/src/extension.ts:612` (`RIGHT`)  
**Blamed base line:** `extensions/vscode-test-resolver/src/extension.ts:586`  
**Introducing path:** `extensions/vscode-test-resolver/src/extension.ts`  
**Introducing commit:** `15e58cea4d308ff39f9d70ff2ebcbccffa4149a5`  
**Mechanism family:** `cleanup-lifecycle`  
**Performance category:** `latency`  
**Confidence:** 0.98

**Mechanism:** An ignored server bind error leaves the tunnel provider promise and per-port in-progress state pending indefinitely.

**Symptom:** A test-resolver tunnel request hangs indefinitely when its local port cannot be bound.

**Fixed behavior:** A server bind failure now rejects tunnel creation, allowing the open-tunnel critical path and factory-in-progress cleanup to complete instead of waiting indefinitely.

**Evidence:** The base implementation creates the tunnel promise with an unused rejection callback and listens without a server error handler. A bind failure therefore leaves the provider promise pending. ExtHostTunnelService awaits the provider, and AbstractTunnelService stores that promise and retains its factory-in-progress key until settlement, so tunnel opening cannot complete. The changed line forwards the pre-listen server error to the promise rejection callback.
