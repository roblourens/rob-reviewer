### 1. repeated-work

**Fix location:** `src/vs/platform/agentHost/node/shared/artifactServerTools.ts:276` (`LEFT`)  
**Blamed base line:** `src/vs/platform/agentHost/node/shared/artifactServerTools.ts:276`  
**Introducing path:** `src/vs/platform/agentHost/node/shared/artifactServerTools.ts`  
**Introducing commit:** `b0dad94048b3b988c8aa325a46ce7998f2abe0bb`  
**Mechanism family:** `repeated-work`  
**Performance category:** `network`  
**Confidence:** 0.94

**Mechanism:** A long artifact reminder duplicated guidance already present in an always-loaded tool definition and was embedded in the first user prompt, causing that text to remain in the conversation context processed by subsequent model requests for the chat.

**Symptom:** Repeated model-input bytes/tokens and associated provider processing/user cost for artifact-enabled chats.

**Fixed behavior:** The PR deletes ARTIFACT\_TOOLS\_INSTRUCTION and unregisters/deletes ArtifactToolsContribution, so new chats no longer append the duplicate reminder to their first model-visible prompt; the non-deferred add\_artifact\_or\_reference tool description remains available with the required guidance.

**Evidence:** In the base revision, ArtifactToolsContribution.onOutgoingTurn returned ARTIFACT\_TOOLS\_INSTRUCTION on each chat's first outgoing turn; AgentSideEffects forwarded contribution instructions as hostInstructions into agent.chats.sendMessage. Copilot injects these as user-prompt additionalContext, Claude via getUserPromptAdditionalContext, and Codex via turn/start additionalContext, placing the long reminder into model context. The add\_artifact\_or\_reference definition is deferLoading:false and already contains the same classification, batching, optional-registration, and exclusion guidance, so the separate reminder duplicated always-loaded tool text. The deleted base line 276 is the long duplicate prompt, and blame resolves it to b0dad94048b3b988c8aa325a46ce7998f2abe0bb.
