### Scenario 1: Agent Host protocol logging during initial connection and relay/WebSocket reconnects

- Effective concurrency: One logger is created per established transport. Relay reconnect attempts are serialized by ReconnectingTransport; each logger retains the existing promise-queue serialization and 1 MiB write coalescing.
- Cache behavior: Directory creation remains memoized per logger; no shared cache is added or defeated. Rotation and batch state are unchanged.
- Mechanism confidence: High: logger construction and queued write ownership are directly visible in the changed factories and AhpJsonlLogger.
- Magnitude uncertainty: Reconnect frequency varies, but the added CPU work is constant per established connection and tiny relative to network establishment.

- Scaling input: Number of files in the current log session's ahp directory. Log sessions are externally retained in a bounded history, while reconnect-created files can increase current-directory cardinality.
- Effective concurrency: A single enumeration runs per view show; source filtering and sorting are synchronous after one directory resolve. Live refresh rereads the selected file but does not re-enumerate sources.
- Cache behavior: No application cache; warm behavior depends on filesystem/provider metadata caching. No repeated enumeration occurs during live file watching.
- Mechanism confidence: High: the removed configuration guard and sole caller's show/load flow are explicit.
- Magnitude uncertainty: Current-session reconnect counts can vary, but this is a user-opened diagnostics surface and performs metadata-only work once per show.

### Scenario 3: Export Agent Host debug logs to a native ZIP or browser-selected folder

- Critical path: Collection and destination selection start concurrently. Collection awaits the existing host collectDebugLogs RPC and local metadata enumeration; after destination selection, save streams/copies each selected client file and the host artifact before completion.

Browser folder export streams files sequentially; native export makes one createZipFile IPC whose implementation streams local files, while remote host artifacts are downloaded in sequential 1 MiB chunks.

- Mechanism confidence: High: all collection loops, provider boundaries, native ZIP implementation, and browser streaming consumer were traced.
