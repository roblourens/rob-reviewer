- Effective concurrency: Startup and navigation are serialized. Tab cleanup uses Promise.all, realistically over one tab; there is no aggregate unbounded concurrency.
- Cache behavior: The fixture explicitly disables HTTP caching and is requested once. forceNew prevents page reuse, but clean per-test editor teardown means the old Google navigation was also normally cold; no repeated miss path is introduced.
- Mechanism confidence: High confidence from the changed test and traced open\_browser\_page implementation.
