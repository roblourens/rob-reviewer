# Performance review: Migrate shared prompts to skills

[PR #336615](https://github.com/microsoft/vscode/pull/336615) at `e49b58b21bdc7aaaf27dbce4b8394b766654a527`

## Findings (1)

### 1. [medium] Keep manual skill discovery off the cold chat critical path

**Finding ID:** `PERF-0C81DC9DD975`  
**Location:** <code>.github/skills/build-champ/SKILL.md:4</code> (<code>RIGHT</code>)  
**Performance category:** <code>latency</code>  
**Mechanism family:** <code>boundary-fanout</code>  
**Resource:** 14 added filesystem resolves, 14 added full-file reads, parsed bytes, and remote filesystem/IPC round trips  
**Scaling:** Cold-path cost grows linearly with the number of migrated skill directories and total skill-body bytes; for this diff it is N=14, with two serial filesystem phases. Remote latency contributes approximately 28 round-trip delays before provider invocation.  
**Outcome:** Increased cold-request latency and a blocked provider-invocation critical path  
**PR causality:** <code>introduced</code>  
**Previous behavior:** These workflows lived under \`.github/prompts/\*.prompt.md\`. Automatic instruction collection on chat send calls \`findAgentSkills\`, so it did not enumerate or read these prompt files; prompt slash-command discovery was a separate cached path.  
**Changed behavior:** This line makes \`build-champ\` one of 14 newly migrated manual-only skills. On the first request after startup or skill-cache invalidation, automatic instruction collection discovers every skill and only filters \`disable-model-invocation\` after reading and parsing each complete \`SKILL.md\`. The same mechanism applies to the other 13 skill files added by this diff.  
**Confidence:** 0.98 — The changed paths, exact added cardinality (14), serial awaits, full-file reads, cache lifecycle, and awaited chat-send call path are directly established in repository code. Only the absolute duration varies with filesystem latency and file sizes, which is reflected in medium severity rather than lower mechanism confidence.

**Causal diff evidence:** The diff moves 14 prompt definitions into separate \`.github/skills/&lt;name&gt;/SKILL.md\` paths and adds \`disable-model-invocation: true\` (for example this added line). \`PromptFilesLocator.findAgentSkillsInFolder\` sequentially awaits \`fileService.resolve(&lt;child&gt;/SKILL.md)\` for every skill directory; \`computeSkillDiscoveryInfo\` then sequentially awaits \`parseNew\`, whose file-backed path calls \`fileService.readFile\`. \`ComputeAutomaticInstructions.collect\` awaits \`findAgentSkills\` during \`ChatService.sendRequest\`, and the provider request starts only after that collection completes. Before these path changes, none of the 14 prompt files participated in \`findAgentSkills\`.

The first chat request after opening the workspace, or after a skill change, can be delayed by 28 added serialized filesystem operations. This is especially visible over SSH, Codespaces, or other high-latency remote filesystems, where it delays time to first model progress even though all 14 skills are explicitly excluded from automatic invocation.

**Evidence:** For the realistic first agent request in this repository, the added directories contribute 14 serial filesystem existence checks followed by 14 serial full-file reads/parses. \`disable-model-invocation\` prevents bodies from entering model context but is evaluated only after those reads. In a remote workspace each await can cross the remote filesystem/IPC boundary, so the fan-out adds roughly 28 serialized round trips plus bytes for all 14 bodies to time-to-provider-invocation. \`cachedSkills\` removes this work on warm requests, but file changes invalidate it; slash-command discovery has a separate cache and does not eliminate these reads.

**Suggested direction:** Preserve manual invocation without serial cold-path fan-out: either keep these workflows as prompt files, or update skill discovery in the same change to run per-directory checks and metadata reads through the existing bounded discovery limiter (and reuse one cached parse across skill and slash discovery) before migrating all 14.
