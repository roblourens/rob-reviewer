## Performance regression fixes detected (1)

### 1. repeated-work

**Fix location:** `src/vs/workbench/contrib/sessions/browser/chat/sessionChatInputToolbar.ts:631` (`RIGHT`)  
**Blamed base line:** `src/vs/workbench/contrib/sessions/browser/chat/sessionChatInputToolbar.ts:629`  
**Introducing path:** `src/vs/sessions/contrib/chat/browser/sessionChatInputToolbar.ts`  
**Introducing commit:** `6622390464a4c2920fba265ead970e1b34a41b59`  
**Mechanism family:** `repeated-work`  
**Performance category:** `ipc`  
**Confidence:** 0.99

**Mechanism:** Equivalent pull-request URIs reconstructed on session state updates failed structural equality, repeatedly invalidating the activity-bar opener derivation. Each invalidation spawned a concurrent opener lookup for every PR and every contributed opener, cancelling in-flight requests and potentially logging those cancellation failures.

**Symptom:** High-frequency session updates caused repeated and cancelled extension-host canOpen IPC and associated cancellation-log churn, scaling with update frequency, pull-request references, and registered openers.

**Fixed behavior:** The new equality function compares each stable artifact id and URI value with resources.isEqual, so equivalent reconstructed links no longer invalidate activityBarOpeners. Real id/link changes plus extension/configuration signals still trigger revalidation, preserving intended refresh semantics while removing repeated opener discovery, cancellation, and extension-host IPC.

**Evidence:** Base line 629 used structuralEquals for arrays containing URI instances. structuralEquals only recursively compares arrays and plain objects, so a state refresh that recreates an equivalent URI makes activityBarOpenerRefs look changed. That invalidates activityBarOpeners, cancels its prior token, and reruns Promise.all(refs.map(...externalUriOpenerService.getOpener...)). getOpener calls getValidOpeners, which invokes every registered opener's canOpen concurrently; MainThreadUriOpeners implements canOpen with proxy.$canOpenUri, an extension-host IPC. The added test recreates identical links ten times and now observes zero additional lookups.
