## Findings (1)

### 1. [low] Skip the WSL probe when all cached distros are disconnected

**Finding ID:** `PERF-FB508D87754E`  
**Location:** <code>src/vs/sessions/contrib/providers/remoteAgentHost/browser/wslAgentHost.contribution.ts:99</code> (<code>RIGHT</code>)  
**Performance category:** <code>subprocess</code>  
**Mechanism family:** <code>eager-work</code>  
**Resource:** One shared-process IPC request and one wsl.exe --list --running --quiet subprocess per poll per Agents window.  
**Scaling:** One grouped probe per five-minute tick per open Agents window, independent of disconnected-distro count; the persisted flag/cache combination keeps this recurring across reloads. It is not a per-distro subprocess fan-out.  
**Outcome:** Unnecessary recurring background process creation and IPC work while all WSL remotes are intentionally disconnected.  
**PR causality:** <code>introduced</code>  
**Previous behavior:** Disconnect removed the cached distro. With the last cached distro removed, \_getProviderEntries() returned an empty list and the poll returned before issuing any IPC request or spawning wsl.exe.  
**Changed behavior:** Intentionally disconnected distros remain in the collection that enables the five-minute running-state poll, but are excluded only after the subprocess result has been fetched.  
**Confidence:** 0.99 — The timer, retained cached entries, post-probe filtering, IPC forwarding, and unconditional cp.spawn in runWslCommand are directly traced. Only the duration and user prevalence are unmeasured.

**Causal diff evidence:** The added isDisconnected check at line 99 runs only after the await listRunningDistros() at line 97. The changed \_disconnectWSLOnDemand now passes { keepEntry: true }, so \_getProviderEntries() continues returning that cached distro and the entries.length === 0 guard no longer skips the probe after the last remote is disconnected.

After disconnecting the only cached WSL remote, leaving the Agents window open still launches wsl.exe every five minutes although no distro is eligible for reconnection. This adds avoidable background process/IPC overhead, including after reload.

**Evidence:** WSLAgentHostContribution installs a five-minute timer (lines 34 and 79). \_reconnectNewlyRunningDistros obtains all cached distros through \_getProviderEntries(), awaits \_wslService.listRunningDistros(), then applies the new disconnected check. WSLRemoteAgentHostService.listRunningDistros forwards over IPC to node/wslRemoteAgentHostService.ts:181, which calls runWslCommand(\['--list', '--running', '--quiet'\]); node/wslRemoteAgentHostHelpers.ts:79 unconditionally spawns wsl.exe. There is no result cache or shared in-flight probe.

**Suggested direction:** Filter intentionally disconnected distros before the empty-entries guard and before listRunningDistros(), retaining one grouped probe only when at least one eligible distro remains.
