### Scenario 2: Offer Copilot runtime slash commands and runtime-only skills while typing or correcting a slash token.

- Critical path: After unchanged customization/argument branches, the Copilot provider awaits runtime command metadata and known-skill metadata concurrently, filters command aliases, emits alias/option combinations, sorts results, and contributes to the aggregate completion response.
- Scaling input: Distinct runtime commands K, aliases per command, structured options, published skill count S, and completion request frequency. Output is bounded by matching command alias/option combinations after hidden-command, skill-duplicate, and alias deduplication.
- Effective concurrency: Runtime catalog and known-skill lookup run in Promise.all. Simultaneous requests for the same command provider share its in-flight catalog query; warm queries issue no list RPC. Host providers remain concurrent with aggregate completion waiting for all. No new per-command or per-alias boundary calls.
- Cache behavior: CopilotSlashCommandProvider caches successful catalogs, including empty results, and joins an in-flight list request. Completion callers wait up to 300 ms; timed-out discovery continues to populate the cache. Failure clears the in-flight/cache state for retry; invalidation isolates old requests. Published customizations bypass known-skill fallback. Plugin marketplace's separate 30-second promise cache and argument branches are unaffected by these extractors.
