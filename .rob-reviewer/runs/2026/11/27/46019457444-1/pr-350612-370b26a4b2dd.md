- Scaling input: One toolbar callback per forwarded structural-change event, not per cell or splice inside that event. Bulk changes with multiple splices produce a single event from compute. Ordinary text edits, scrolling, and output updates do not emit this structural event.

- Cache behavior: No new cache is needed for the constant-time empty-state query. Existing markdown preview mappings suppress duplicate creation and compare content, metadata, and visibility before posting updates.
- Mechanism confidence: High: the event payload groups splices, the widget forwards it once, and updateClass does not traverse cells, rebuild menus, or call webview services.

### Scenario 4: Detach, replace, reuse, or dispose a notebook editor; hover or keyboard-focus the insertion row
