- Effective concurrency: File changes are coalesced by the existing 500 ms ThrottledDelayer; effective-setting changes are emitted synchronously once after equality comparison, and UI listeners execute serially on the UI thread.
- Cache behavior: The account policy service retains the previous effective bag and suppresses unchanged events. Sessions overlays compare full options, customization widgets retain a message key, and open picker/menu listeners compare the currently shown support URL before changing UI.
