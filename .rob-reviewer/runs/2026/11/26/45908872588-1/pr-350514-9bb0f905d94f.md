## Findings (1)

### 1. [medium] Keep .git and node\_modules exclusions non-overridable

**Finding ID:** `PERF-6408B7DDEC24`  
**Location:** <code>src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/syncedCustomizationBundler.ts:117</code> (<code>RIGHT</code>)  
**Performance category:** <code>io</code>  
**Mechanism family:** <code>boundary-fanout</code>  
**Resource:** Directory resolve/readdir operations, child stat calls, matching-file buffers and hashes, and remote content reads.  
**Scaling:** O(D + N) extra traversal per shared scope's debounced re-resolution for newly reachable dependency directories and entries, plus matching-file bytes. Filesystem operations are limited to 10 concurrently per bundler; upstream URI deduplication and scope sharing do not remove this within-skill work.  
**Outcome:** Increased session readiness latency and repeated filesystem I/O; larger buffers and remote transfers for matching dependency files.  
**PR causality:** <code>introduced</code>  
**Previous behavior:** SKILL\_DIRECTORY\_IGNORE always pruned .git/node\_modules at their roots. Only those root entries were statted; their descendants were neither traversed nor read, hashed, or copied.  
**Changed behavior:** A skill .gitignore allowlist such as \`\*\\n\!\*/\\n\!\*.md\` re-includes .git/node\_modules directories, allowing recursive traversal and bundling of matching files.  
**Confidence:** 0.98 — Static tracing proves child negations bypass parent rules (ignoreFile.ts:130-136); existing IgnoreFile tests verify that behavior. The changed check gates recursion. Dependency-tree size and latency are unmeasured.

**Causal diff evidence:** Added line 117 replaces the fixed SKILL\_DIRECTORY\_IGNORE check with the layered ignore check. Added line 144 makes that fixed exclusion a parent which child negations can override.

Opening an agent session with a forwarded skill containing dependencies and a directory-negation allowlist now traverses potentially thousands of dependency entries, delaying readiness. Warm customization re-resolutions repeat the walk; included documentation also increases hashing, memory, and cold remote transfers.

**Evidence:** SKILL\_DIRECTORY\_IGNORE excludes .git/node\_modules (line 31). IgnoreFile.parseIgnoreFile returns false for a child inclusion before consulting its parent (ignoreFile.ts:130-136). collectDirectoryFiles resolves each visited directory and stats every child before filtering (lines 98-125). \_bundle reads and hashes accepted entries before checking the nonce cache (405-424). AgentCustomizationScope awaits bundling before initial resolution; session claim awaits that resolution (agentHostSessionHandler.ts:1304). AgentPluginManager copies cold/changed-nonce bundles (agentPluginManager.ts:151-164).

**Suggested direction:** Keep SKILL\_DIRECTORY\_IGNORE as an independent non-overridable guard alongside the layered gitignore check. Cover \`\*\`, \`\!\*/\`, and \`\!\*.md\` with a test proving excluded-tree descendants are not traversed or bundled.
