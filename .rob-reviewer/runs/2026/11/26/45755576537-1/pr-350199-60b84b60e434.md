- Mechanism confidence: High: traced guards precede the unchanged service and media operations; grouped edit and chunk cardinalities are explicit in code.

### Scenario 5: Close, dispose, reload, or Save As a custom/Markdown editor and transfer ownership

- Scaling input: Number of live panels and their lifetime; repeated open/close and existing HTML reload frequency. New retained state is constant per live panel, not proportional to edit history.

Inspected the async onMove callback as a possible disposal race, but Markdown does not supply moveCustomTextEditor, and CustomEditorInput's stored \_moveHandler has no invocation in the inspected repository, so no reachable new retention scenario was established there.

- Mechanism confidence: High for normal lifetime cleanup and unchanged reload behavior. Insufficient live call-path evidence for an asynchronous move-listener leak, so it was not reported.
