- Effective concurrency: Static skill validation is represented by one contribution promise. Skill retrieval uses one CachedPromise-backed request, coalescing concurrent callers; local prompt assembly then filters the resolved in-memory list.
- Cache behavior: On a cold extension-host request, getSkills crosses IPC once and resolves discovered skills; warm requests reuse CachedPromise until the existing change event invalidates it. The diff changes neither keys nor invalidation.
- Mechanism confidence: High: the changed array is propagated as metadata and local matching remains true; traced registration, cached IPC retrieval, and local filtering show no added work.
- Magnitude uncertainty: Exact skill count and cold discovery duration vary by installed extensions and workspace, but this manifest edit does not increase either.

### Scenario 3: Copilot CLI / Agent Host customization UI requests available customization items

- Critical path: The customization provider awaits agents, instructions, skills, hooks, and plugins concurrently, then returns their metadata to the chat session customization consumer.
- Scaling input: The number of discovered customization metadata entries. This diff decreases the returned skills list by one for copilotcli sessions.
- Effective concurrency: Five customization categories run in one Promise.all. Skills use a single cached full-list request followed by an in-memory filter and map; there is no per-item boundary call.
- Cache behavior: Cold skills access performs the shared cached discovery IPC; warm requests reuse it. Filtering by sessionTypes happens after retrieval, so the change does not alter cold boundary work but reduces one mapped/serialized result item.
- Mechanism confidence: High: the provider implementation explicitly filters with isEnabledForCopilotCLI after cached retrieval and maps only matching skills.
- Magnitude uncertainty: The total customization count varies by workspace, but the direction is definitively non-regressive because one item is removed and no request is added.
- Expensive boundaries:
