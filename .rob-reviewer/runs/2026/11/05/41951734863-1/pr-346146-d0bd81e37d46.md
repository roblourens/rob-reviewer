- Scaling input: S live sessions times genuinely changed model snapshots; each sync serializes M registered models. The diff does not increase S, event frequency, or M.
- Effective concurrency: A per-session queue serializes syncs; separate live sessions may sync concurrently as before. No new burst or missing coalescing is introduced by the field.
- Cache behavior: Each sync reads the bridge registry's cached snapshot and reuses the memoized proxy. Stable modelId values participate in existing deep equality and therefore do not defeat no-op suppression.
- Mechanism confidence: High confidence from the event listener, per-session queue, merge, equality check, and provider.sync call path.
- Magnitude uncertainty: The number of simultaneous sessions varies, but boundary cardinality and scheduling are unchanged by this PR.
- Expensive boundaries:

- Verdict: No reportable regression. The PR neither fans out more RPCs nor repeats synthesis more often; it only enriches existing model entries.
