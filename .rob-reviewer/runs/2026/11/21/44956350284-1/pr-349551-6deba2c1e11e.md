Each custom name is hashed once per invocation report and reused for the two existing telemetry events; tool results and the available-tool collection are not hashed.
- Effective concurrency: Hashing and event construction execute on the host's JavaScript thread. Deferred reports may flush in a synchronous loop, as before. Existing PostChannel sends asynchronously; its SDK-owned batching/concurrency policy is unchanged.
- Cache behavior: The fixed allowlist is initialized once and checked with Set.has. Custom hashes are not cached across invocations, but the same result serves both invocation events. Existing pending reports are removed before flushing. Collector initialization is coalesced through \_asyncAiCore.
- Mechanism confidence: High confidence in the traced per-report hash, reuse across both events, duplicate suppression, deferred flushing and unchanged transport paths.

- Critical path: Reporter methods still prepare events before AgentHostTelemetryService.publicLog2 rejects them by telemetry level. The diff therefore hashes custom names even when events are dropped; it does not perform any new awaited operation.
- Scaling input: One custom-name hash per invocation report, approval report or eligible diagnostic report, not per streaming delta or result character.
- Effective concurrency: Synchronous per-report CPU work on the host thread, with no collector tasks scheduled for dropped usage events.
- Cache behavior: Fixed process-wide allowlist; no retained custom-name keys and no negative-cache behavior. Hashes are not cached.
- Mechanism confidence: High confidence that hashing precedes the existing usage-level gate; service and NullTelemetryService paths do not introduce network, IPC, subprocess, database or filesystem calls for these dropped records.
- Magnitude uncertainty: Disabled telemetry does gain small unnecessary CPU work, but neither realistic event frequency nor identifier sizes establishes material user-visible degradation.
- Expensive boundaries: none found
- Verdict: Omit as a finding: identifier-sized hashing before an existing gate is not independently a concrete material performance regression.
