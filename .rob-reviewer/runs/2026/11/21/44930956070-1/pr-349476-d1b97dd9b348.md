## Performance regression fixes detected (1)

### 1. eager-work

**Fix location:** `src/vs/sessions/contrib/onboardingTours/browser/newSessionViewV3Prompt.ts:959` (`RIGHT`)  
**Blamed base line:** `src/vs/sessions/contrib/onboardingTours/browser/newSessionViewV3Prompt.ts:961`  
**Introducing path:** `src/vs/sessions/contrib/onboardingTours/browser/newSessionViewV3Prompt.ts`  
**Introducing commit:** `9b4e244184cba1b6ddc19c9bd93254f9bdfd560c`  
**Mechanism family:** `eager-work`  
**Performance category:** `latency`  
**Confidence:** 0.96

**Mechanism:** Repository-resolution misses unnecessarily awaited IGitService.openRepository before returning noRepository. GitService waits on a barrier that opens at delegate registration or 10 seconds after service construction. A registered delegate instead queues every open globally and crosses extension-host IPC; its cold path activates the Git extension and probes the directory. This was one extra open per unresolved primary-folder lookup, not per workspace folder or issue.

**Symptom:** During early onboarding with an unsupported/missing GitHub remote and no applicable Agent Host metadata wait (for example, an Enterprise account selecting a public GitHub repository), prompt insertion/final option resolution could wait for the remaining Git-service registration barrier or the 10-second overall lookup timeout, despite having no useful repository to discover. With a registered delegate, the miss also incurred serialized IPC/probing.

**Fixed behavior:** After unchanged session metadata, URI, .git/config, and applicable Agent Host metadata checks fail, return undefined directly; remove the Git-service dependency and redundant awaited extension lookup.

**Evidence:** Deleted base line 961 awaited \_gitService.openRepository after local config resolution failed; added head lines 958-959 now return undefined immediately. run() awaits \_resolveGitHubPromptWithFallback before animatePrompt (299-306); \_resolveGitHubPrompt awaits repository resolution (661-667). Both GitHub prompt modes have a 10-second outer race (41, 432-459, 616-639). GitService.openRepository waits on AutoOpenBarrier(10\_000) (git/browser/gitService.ts:20,47-58). MainThreadGitExtensionService.openRepository globally sequences and unconditionally calls $openRepository (102-126); extHostGitExtensionService.ts:207-214,373-392 activates the Git API and calls its openRepository. Enterprise mode bypasses Agent Host waiting (prompt.ts:941), establishing a reachable miss even for an Agent Host draft. Blame of the removed await identifies the introducing commit.
