- Effective concurrency: One pending cleanup traversal per navigation stack; synchronous event handling otherwise.
- Cache behavior: The guard is navigation state, not a data cache. \_pendingHistoryPop coalesces cleanup while awaiting popstate; clean startup performs no traversal.
- Mechanism confidence: High: constructor and synchronization paths were inspected directly, including reload and stale-Forward coverage.

- Expensive boundaries:

- Verdict: No reportable regression: no heavyweight initialization, remote request, or input-scaling startup work was introduced.
