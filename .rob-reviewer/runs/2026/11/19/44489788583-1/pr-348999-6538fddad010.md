### Scenario 2: Display the Context Size cell hover or construct full model-hover metadata.

- Critical path: The cell renderer eagerly builds its short MarkdownString as before and registers an existing delayed hover callback. Showing the hover consumes that string. The changed full getModelHoverContent helper performs the same local metadata construction; repository search found its chatManagement version referenced only by tests, while the actual model-name column uses getModelNameHoverContent.
- Scaling input: One short token-count string per rendered cell and one hover registration per cell render. The full-hover helper is proportional to the same pre-existing metadata fields and capability entries, with only a constant-size token-count segment changed.
- Effective concurrency: Synchronous local string construction and existing delayed hover scheduling; no new tasks, requests, or parallel fan-out.
- Cache behavior: Each existing cell render rebuilds the short hover content. Hover callbacks reuse that render's MarkdownString; elementDisposables is cleared on rerender and disposed with the template. No added cache, retained history, negative-cache behavior, or retry path.
- Mechanism confidence: High: traced both hover helpers, their references, formatTokenCount, MarkdownString.appendText, and element disposal. The changed operation is bounded string escaping without filesystem, database, network, subprocess, or IPC calls.
- Magnitude uncertainty: Hover frequency is unmeasured. appendText adds escaping passes over the compact numeric count, not over a catalog or large metadata payload.
- Expensive boundaries: none found
- Verdict: No reportable regression. Escaping a compact numeric count instead of appending it directly does not establish a meaningful scaling or retention regression, and hover lifetime is unchanged.

- Mechanism confidence: High: compared the deleted inline accessibility implementation with the added helper and inspected its only production caller and the shared numeric function. No expensive external boundaries are reachable from the changed calculation.
- Magnitude uncertainty: Accessibility invocation frequency and label lengths are unmeasured, but the extraction preserves the previous allocation and traversal structure.
- Expensive boundaries: none found
- Verdict: No reportable regression. This is a behavior-preserving extraction apart from the intended displayed numeric value, with no increased invocation cardinality or retained state.
