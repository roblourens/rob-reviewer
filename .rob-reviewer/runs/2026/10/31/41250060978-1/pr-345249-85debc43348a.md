# Performance review: Keep idle sash gripper styling from restyling the whole workbench

[PR #345249](https://github.com/microsoft/vscode/pull/345249) at `85debc43348a8b650fadf7d1e7270ea4588d5710`

## Findings

No high-confidence performance findings.

## Performance regression fixes detected (1)

### 1. synchronous-ui-work

**Fix location:** `src/vs/workbench/browser/media/style.css:70` (`RIGHT`)  
**Blamed base line:** `src/vs/workbench/browser/media/style.css:69`  
**Introducing path:** `src/vs/workbench/browser/media/style.css`  
**Introducing commit:** `f5d95e4ba024c912a62793b3167eeb119fb150dc`  
**Mechanism family:** `synchronous-ui-work`  
**Performance category:** `rendering`  
**Confidence:** 0.98

**Mechanism:** Frequently toggling inherited CSS custom properties on the workbench root invalidated computed style for every descendant and forced large synchronous browser style recalculations on mouse activity and idle transitions.

**Symptom:** With large chat/session DOMs, showing or hiding sash grippers blocked the renderer main thread for roughly 0.4 seconds per transition and materially delayed session switching.

**Fixed behavior:** The added descendant selector at style.css:70 places the custom properties directly on `.monaco-sash` descendants. Root class toggles now invalidate and recompute only sash elements while preserving inheritance to each sash pseudo-element, as covered by the added computed-style test and existing gripper transition tests.

**Evidence:** In the base revision, style.css:69 assigns two inherited custom properties on `.monaco-workbench.sash-grippers-hidden`. `SashGrippersController.registerContainer` removes that root class on mouse movement and re-adds it after the idle timer (sash.ts:103-109), so each idle/active transition invalidates inherited style across the entire workbench even though searches show the properties are consumed only by sash `::after` rules in sashHandles.css and sessions workbench.css. The PR's measured scenario reports synchronous 393-400 ms style recalculations over about 34,300 elements during these toggles. Blame identifies f5d95e4ba024c912a62793b3167eeb119fb150dc as introducing the base selector.
