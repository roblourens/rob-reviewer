### 1. repeated-work

**Fix location:** `src/vs/workbench/contrib/chat/browser/remoteAgentHost/missionControlSharingService.ts:106` (`RIGHT`)  
**Blamed base line:** `src/vs/workbench/contrib/chat/browser/remoteAgentHost/remoteAgentHost.contribution.ts:100`  
**Introducing path:** `src/vs/workbench/contrib/chat/browser/remoteAgentHost/remoteAgentHost.contribution.ts`  
**Introducing commit:** `431af7bbe286c90b2df828d495cf31e3e33f0fd7`  
**Mechanism family:** `repeated-work`  
**Performance category:** `startup`  
**Confidence:** 0.96

**Mechanism:** The initial Agent Host connection event queued a second full Mission Control configure operation behind the first, duplicating authentication lookup, workspace-root preparation, management IPC, filesystem realpath work, GitHub identity resolution, and environment registration on every enabled cold startup.

**Symptom:** Mission Control opt-in or restored startup performed two serialized registration passes, extending readiness and duplicating IPC, filesystem, and network work.

**Fixed behavior:** The new sharing service ignores the Agent Host start event during the initial in-flight registration because \_configured is false, then marks it configured only after configureMissionControl succeeds. A later real host restart still clears \_configured and schedules exactly one replacement registration.

**Evidence:** In the base contribution, the initial \_configure path called IAgentHostService.startAgentHost(), then awaited configureMissionControl over LocalAgentHostManagementConnection. That management channel cannot resolve until LocalAgentHostServiceClient reaches Connected; \_handleConnectionState fires onAgentHostStart at that point. The base onAgentHostStart handler at line 100 unconditionally incremented the generation and scheduled another throttled \_configure. Because the first \_configure was active, Throttler retained one queued run; after the first IPC/network registration settled, that queued run repeated authentication.getSessions, workspace-root collection, startAgentHost, and configureMissionControl. The downstream MissionControlEnvironment registration resolves owner identity, realpaths roots, and performs GitHub registration/check-in network work. The PR's new line 106 gates the event on \_configured, which remains false until the initial configureMissionControl has completed, while the added test still proves reconfiguration after a genuine later host restart.
