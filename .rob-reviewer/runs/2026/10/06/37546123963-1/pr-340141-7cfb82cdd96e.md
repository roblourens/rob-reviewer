- Effective concurrency: A provisioning call performs one create flow and one connection flow. Existing address-keyed connection tracking/reuse prevents duplicate trackers for the same live address; the diff adds no limiter, queue, fan-out, or concurrency burst.
- Cache behavior: No new cache is introduced. Existing live-connection reuse returns before creating telemetry, while a cold new environment creates one tracker. The timestamp is carried only on the first create-to-connect handoff and is not persisted or reused on later dials.
- Mechanism confidence: High confidence: call sites, address-keyed ownership, and boundary counts are explicit in the changed code and surrounding service flow.
