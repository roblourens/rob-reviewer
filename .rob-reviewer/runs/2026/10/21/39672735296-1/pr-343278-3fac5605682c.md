### Scenario 2: Click Continue in Copilot for an archived remote Local chat

- Critical path: The action synchronously translates source requests and constructs a transcript, then awaits Copilot provider resolution and opens one new Copilot session before restoring the draft. These steps are required before the destination can be shown.
- Scaling input: Synchronous transcript preparation scales with request count and response text size; the attached result is capped at 20,000 characters. This implementation and cost already apply to every transcript-only continuation and are not changed by this PR; the diff extends the explicitly requested workflow to archived sources.
- Effective concurrency: The static pending map coalesces duplicate invocations for the same source resource. Different source resources are independent, but the realistic trigger is a user click on one open chat rather than collection fan-out.
- Cache behavior: Provider registration is cached after cold activation. In-flight continuation is coalesced per source resource; transcript data is computed once per explicit attempt and not retained after draft transfer beyond the destination attachment.
- Mechanism confidence: High for the one-action call path, transcript scaling, provider activation, and per-resource coalescing; exact Agent Host startup latency depends on warm state.
- Magnitude uncertainty: Very large archived histories can make the pre-existing full-history conversion/allocation noticeable, but the diff neither changes its per-action complexity nor creates repeated or automatic invocation, so it does not meet the causality threshold for a finding.
- Expensive boundaries:
  - IPC at <code>src/vs/workbench/contrib/chat/browser/actions/chatContinueInAction.ts:274 and src/vs/workbench/contrib/chat/browser/chatSessions/chatSessions.contribution.ts:1007</code>: Resolve/activate the Copilot chat-session provider via extension activation when cold.; cardinality: At most one activation attempt per explicit action; warm runs return from the registered content-provider cache.
    - Introduced by diff: true; previous behavior: The archived unsupported-host scenario had no banner action and the archived guard rejected direct invocation before provider resolution.; critical-path effect: Cold provider activation blocks opening the destination; warm provider resolution is in-memory.
  - IPC at <code>src/vs/workbench/contrib/chat/browser/actions/chatContinueInAction.ts:311 and src/vs/workbench/contrib/chat/browser/chatSessions/chatSessions.contribution.ts:1823</code>: Open and resolve one untitled Copilot session through the contributed session provider/Agent Host path.; cardinality: One destination session per successful explicit continuation.
    - Introduced by diff: true; previous behavior: No destination was opened for an archived unsupported-host chat because the action was not offered and the archived guard rejected it.; critical-path effect: Destination session materialization must finish before its draft is populated and the action completes.
- Verdict: No reportable regression: the new boundaries are a single, user-requested destination creation with duplicate-click coalescing. The potentially unbounded intermediate transcript preparation is pre-existing and not materially amplified in frequency or cardinality by the diff.
