## Performance regression fixes detected (1)

### 1. serialization-allocation

**Fix location:** `src/vs/platform/agentHost/node/copilot/copilotSessionLauncher.ts:700` (`RIGHT`)  
**Blamed base line:** `src/vs/platform/agentHost/node/copilot/copilotSessionLauncher.ts:661`  
**Introducing path:** `src/vs/platform/agentHost/node/copilot/copilotSessionLauncher.ts`  
**Introducing commit:** `ff61d31952aa3ca982afe61db10f530d5db0b38e`  
**Mechanism family:** `serialization-allocation`  
**Performance category:** `network`  
**Confidence:** 0.92

**Mechanism:** Registering only the model's maximum prompt budget delayed compaction until the full advertised window, causing every later turn in long sessions to repeatedly serialize, transmit, and process a much larger prompt history than a user-selected smaller budget requires.

**Symptom:** Long BYOK sessions on very large-context models incur increasing per-turn request bytes, token processing, and latency until the full advertised prompt limit is reached.

**Fixed behavior:** The session launcher now resolves an offered BYOK context size per session and registers the model with that bounded prompt/window limit; live changes re-register through the existing serialized provider.sync path before setModel, and resume uses the stored selection.

**Evidence:** Before this PR, synthesizeByokSessionConfig copied each BYOK model's advertised maxPromptTokens directly into ProviderModelConfig (base line 661), so the runtime's compaction budget could not reflect a smaller model selection. The added getByokSessionModelLimits path resolves the selected/default context size and lowers both maxPromptTokens and maxContextWindowTokens; the added bundled-runtime integration test demonstrates that these ProviderModelConfig limits become session.usage\_info.tokenLimit and assistant.usage.maxPromptTokens at launch, after provider.sync, and on resume. Thus a long BYOK conversation that previously remained eligible to grow to the advertised 968K prompt budget can now compact at the selected 200K budget before subsequent turns.
