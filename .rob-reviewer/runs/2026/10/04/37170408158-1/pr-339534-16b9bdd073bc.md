- Mechanism confidence: High confidence from the wrapper handled-event set, listener registration order, and pre-existing unhandled trace callback that the new typed path replaces rather than duplicates event logging.
- Magnitude uncertainty: Exact indexed-search event frequency and trace logger implementation vary by runtime and log level, but the diff reduces serialized content relative to the existing path and does not increase boundary cardinality.

- Verdict: No reportable regression: one pre-existing trace serialization/log operation remains one operation per event, with less data and sensitive error text removed.
