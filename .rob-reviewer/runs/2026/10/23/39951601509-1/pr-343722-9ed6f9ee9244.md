### Scenario 1: Diagnostics for an open GitHub Copilot agent file containing a skills header, including edits and harness/provider inventory changes

- Critical path: After the ModelTracker's 200 ms debounce, validation parses the model from a version-keyed cache, awaits tool validation, then awaits resolveAgentFileSkills before publishing markers. Promise.all still waits only for matching descriptors that have an itemProvider; providerless descriptors resolve synchronously. The diff newly allows the final in-memory name/availability loop to run when all actual providers succeeded, but adds no boundary to the critical path.
- Scaling input: Boundary cost scales with the effective number of matching descriptors that actually have providers, plus cold customization files/plugins within each provider; providerless descriptors add no boundary cardinality. The newly reachable CPU work scales with authored skill entries times returned skill entries, generally a small frontmatter list against one grouped catalogue.
- Effective concurrency: Each open model has its own debounced tracker. Within one skill resolution, all matching descriptors are queried concurrently with Promise.all; providerless descriptors schedule no provider work. The local prompts provider resolves five customization categories in parallel, while configured skill source folders are scanned sequentially behind its cached skill discovery. Remote plugin expansions are parallel per plugin and reuse a nonce-keyed expansion cache. None of this concurrency changes in the diff.
- Cache behavior: The resolver itself remains uncached and calls actual providers on each completion/hover/validation request as before. Local skill discovery is cached and coalesced by PromptsService, file-location caches are invalidated by update events, remote plugin expansion is keyed by plugin URI plus nonce/label, and failures still return undefined to preserve fail-open behavior. The only changed negative state is that absence of an itemProvider is treated as a settled empty inventory for isResolved; no inventory bytes or keys are retained.
- Mechanism confidence: High confidence that provider boundaries and concurrency are unchanged and that only bounded local validation becomes reachable, based on the changed return value, isResolved predicate, caller control flow, and provider implementations.
- Magnitude uncertainty: A pathological agent file could contain many authored skill entries and an unusually large catalogue, but the added work is simple in-memory filtering/marker construction after unchanged provider work; there is no evidence of user-visible latency at realistic sizes.
- Expensive boundaries:
  - filesystem at <code>src/vs/workbench/contrib/chat/browser/aiCustomization/promptsServiceCustomizationItemProvider.ts:provideChatSessionCustomizations</code>: Discover and parse prompt/customization files, including skills and other customization categories returned by the local prompts-service item provider; cardinality: One provider call per matching descriptor with an itemProvider for each validation run; the local descriptor performs grouped category discovery, with skill discovery cached/coalesced by PromptsService and invalidated by file events. A providerless matching descriptor performs zero calls.
    - Introduced by diff: false; previous behavior: The same actual providers were called with the same session resource, cancellation token, and Promise.all fan-out; a providerless descriptor merely forced isResolved false after all calls completed.; critical-path effect: Cold discovery is awaited before skill diagnostics can publish; warm discovery reuses cached promises/results. The newly reachable marker loop runs only after these unchanged calls complete.
  - IPC at <code>src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentCustomizationItemProvider.ts:\_expandPluginContents</code>: Expand agent-host plugin directories through the agent-host filesystem/content expander when a remote harness provider supplies customization items; cardinality: At most one expansion per uncached plugin nonce/label during an actual provider call; expansions are parallel and warm entries use \_expansionCache. Providerless descriptors contribute zero expansions.
    - Introduced by diff: false; previous behavior: Identical remote provider calls and cache lookup occurred before the sentinel changed from undefined to an empty array.; critical-path effect: Cold remote expansion is awaited by the provider and therefore by diagnostics; warm expansion is served from the provider cache. The diff neither adds nor relocates this operation.
- Verdict: No reportable performance regression. The PR makes successful mixed provider/providerless inventories authoritative without increasing expensive call count; the intended local diagnostics work is bounded by frontmatter/catalogue size and debounced per open model.

### Scenario 2: Skill value completion while editing a GitHub Copilot agent file

- Critical path: A completion request inside the skills sequence awaits resolveAgentFileSkills and then groups returned skills by name to build suggestions. This caller does not inspect catalogue.isResolved, so changing the providerless sentinel has no effect on its critical path or post-processing.
- Scaling input: Work scales with actual provider count and returned inventory size, then linearly groups skills by name. Providerless descriptor count contributes only trivial Promise entries and did so before the diff.
- Effective concurrency: Matching actual providers are queried concurrently by Promise.all; providerless descriptors return immediately. Concurrent editor completion requests are governed by their cancellation tokens, exactly as before. Provider-internal cache and concurrency behavior is unchanged.
- Cache behavior: No resolver-level cache was added or removed. Local discovery/file caches and remote nonce-keyed expansion caches behave identically on cold and warm requests; provider failures still yield unresolved catalogues, although this caller ignores that flag.
- Mechanism confidence: High; the completion caller uses catalogue.skills only, and that array is identical for undefined versus empty providerless inventory.
- Magnitude uncertainty: Underlying cold provider duration varies by workspace and remote plugin count, but changed code does not affect it.
- Expensive boundaries:
  - filesystem at <code>src/vs/workbench/contrib/chat/common/promptSyntax/languageProviders/promptHeaderAutocompletion.ts:skills completion branch -&gt; resolveAgentFileSkills</code>: Resolve local prompt/customization inventories used to construct skill suggestions; cardinality: One call per matching descriptor with an itemProvider per completion request; zero for providerless descriptors, with warm provider caches reducing underlying scans.
    - Introduced by diff: false; previous behavior: Completion already received the same skills array because flatMap converted both undefined and empty inventories to no skills; isResolved was not consumed.; critical-path effect: Actual provider completion is awaited before suggestions are returned. The diff does not change the calls, their arguments, or waiting behavior.
  - IPC at <code>src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentCustomizationItemProvider.ts:provideChatSessionCustomizations</code>: Resolve remote agent-host customization inventories and uncached plugin contents when the matching provider is remote; cardinality: One provider invocation per matching remote descriptor and at most one uncached expansion per plugin nonce/label; no call for a providerless descriptor.
    - Introduced by diff: false; previous behavior: The same remote provider invocation and expansion cache path was used before the change.; critical-path effect: Awaited for remote skill suggestions, unchanged by this diff.
- Verdict: No performance change in the completion scenario.

### Scenario 3: Hovering a skill reference in a GitHub Copilot agent file

- Critical path: A hover over a scalar skill entry awaits resolveAgentFileSkills, filters matching names, and formats details. The hover path does not inspect catalogue.isResolved, so the changed sentinel does not affect returned inventory processing or latency.
- Scaling input: Provider cost scales with actual providers and cold inventory/plugin contents; local hover matching is linear in the combined skill catalogue. The diff changes neither scale nor frequency.
- Effective concurrency: All matching actual providers run concurrently in Promise.all; providerless descriptors perform no provider operation. Hover cancellation is passed through to providers as before.
- Cache behavior: Resolver calls and provider caches are unchanged; providerless emptiness is recomputed trivially and retained nowhere. Empty successful actual-provider inventories remain empty successes, and failed providers remain undefined/unresolved.
- Mechanism confidence: High; this caller never reads isResolved, and the skills array is unchanged.
- Magnitude uncertainty: Cold remote inventories may be slow, but there is no diff-induced change to those operations.
- Expensive boundaries:
  - filesystem at <code>src/vs/workbench/contrib/chat/common/promptSyntax/languageProviders/promptHovers.ts:getSkillHover -&gt; resolveAgentFileSkills</code>: Resolve local customization inventories for skill metadata shown in hover; cardinality: One call per matching descriptor with an itemProvider for a hover request; zero calls for providerless descriptors, with provider caches serving warm discovery.
    - Introduced by diff: false; previous behavior: The same provider results and matching/filtering work occurred because catalogue.skills was already empty for the providerless slot.; critical-path effect: Provider resolution is awaited before hover content can be returned; unchanged by the diff.
  - IPC at <code>src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentCustomizationItemProvider.ts:provideChatSessionCustomizations</code>: Resolve remote agent-host inventory and expand uncached plugin content for a remote matching harness; cardinality: One remote provider call per matching remote descriptor, with per-plugin expansion only on nonce/label cache misses; providerless descriptors produce no call.
    - Introduced by diff: false; previous behavior: Identical before the sentinel change.; critical-path effect: Awaited on remote hover inventory resolution, with no change in placement or cardinality.
- Verdict: No performance change in the hover scenario.

**Summary:** Reviewed the complete two-file diff and traced diagnostics, completion, and hover consumers through local and remote provider boundaries. The sentinel change does not add provider calls, filesystem/IPC work, cache entries, retained state, or concurrency; only bounded debounced in-memory diagnostics become authoritative after the same providers finish. No performance finding or regression-fix learning record is warranted.
