- Magnitude uncertainty: Browser repaint cost varies by platform and terminal-list area, but the changed invalidation covers one existing container and the existing visible rows only; no evidence supports frame-scaling layout work beyond normal CSS repaint.
- Expensive boundaries: none found
- Verdict: No reportable regression. The diff preserves the existing drop-target class transition and adds only a static non-drop background and row geometry, with no new synchronous geometry reads, listener fan-out, or expensive boundary.
